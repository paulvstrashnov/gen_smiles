# Канонизация SMILES с использованием алгоритма Моргана

## Цель
Реализовать алгоритм Моргана для канонизации SMILES (текстовая запись для представления молекул).

## Что нужно сделать
1. Реализовать парсер MOL-файлов в граф.
2. Реализовать алгоритм Моргана для вычисления эквивалентности атомов.
3. Реализовать канонизацию — вывод единственного представления молекулы.
4. Написать тесты для проверки работы.

## Требования
- Python 3.7+
- networkx

## Запуск тестов
```bash
pip install -r requirements.txt
python -m pytest tests/
